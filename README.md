# Flutter Wizard — legal pages

The privacy policy and terms for the Flutter Wizard app, published so the app
stores have a public URL to point at.

These pages are **generated**, not hand-edited. The source is
`assets/jsons/curriculum/../legal/documents.json` in the app repo, which is the
same file the app reads on its Support & legal screen — so the hosted policy
and the in-app one cannot disagree. Regenerate with
`python3 tools/build_legal_site.py` and copy the `site/` folder here.

- https://thedevvarun.github.io/flutter-wizard-site/privacy.html
- https://thedevvarun.github.io/flutter-wizard-site/terms.html
